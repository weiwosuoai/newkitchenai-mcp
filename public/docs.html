NewKitchenAI

Kitchen Design Reference MCP

Read-only public information for exploring AI kitchen design from your photo. Look up kitchen styles and finishes, compare AI examples and check one-time pricing from an MCP-compatible assistant.

This MCP does not generate images, upload photos, access accounts or spend credits. To create a design, use the kitchen design tool. Your own designs require Google sign-in and purchased credits.

Connect

Remote endpoint, Streamable HTTP, no API key required:

https://newkitchenai.com/mcp

In a client that accepts a remote MCP URL, add the endpoint above. For Cursor:

{
  "mcpServers": {
    "newkitchenai": { "url": "https://newkitchenai.com/mcp" }
  }
}

Available tools

  • get_product_info — capabilities, requirements, limits and official links.
  • list_kitchen_styles — 14 styles with preview images.
  • get_kitchen_materials — cabinet finishes, counters, backsplash, flooring, lighting and kitchen elements.
  • get_design_examples — remodel, unfinished-room and sequential refinement examples.
  • get_pricing — website pricing; a dated snapshot is clearly marked if the website is unavailable.
